# Moonlight Events website

React + Vite + Tailwind CSS + Lucide + Framer Motion. Bilingual (SQ default / EN).

## Run locally
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in /dist
    npm run preview
